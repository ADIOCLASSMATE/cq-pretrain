## 已修正的质量和续跑问题

- 原生 QA 不被统一替换成 caption；多轮和交错保留上下文及全部图片。真实 `coco_caption` 的描述型 conversation 需由固定来源适配器识别，保留其长度和语言约束。
- 可选 layout 生成或检查失败单独记录，不连带否决已通过的原生标注。
- API 图片优先保留原 PNG／JPEG 字节；必要时做完整图像 EXIF 校正、白色透明底和无损 PNG 转换，并记录实际发送内容身份，不裁掉细节。
- 冻结检测器缓存绑定图像 SHA、权重、预处理、代码和运行时身份；成功模型缓存还绑定 prompt、上下文、精度与处理器。
- 截断输出按上限增加 token 预算，不把截断 JSON 缓存成成功；异常退出的资格验证进程有有界重试，不因此重启模型 Job。
- 每次执行保留不可覆盖的 attempt 身份；增量发布读取 parent 链并按原记录身份 upsert，避免新批次覆盖旧库。
- 相同模型／图文请求使用 single-flight 共享在途推理；16 个相同并发请求的测试只发出一次 HTTP，并返回同一完整结果。临时文件改为同目录唯一名称；没有把尚未复现的文件损坏当成实际事故。

运行包装器 [production/supervise.py](production/supervise.py) 已后台启动，持续等待两个经过资格验证的 ready 端点，再启动或续跑同一 canary。只有可归因于传输／端点的暂时失败，才在端点新代际就绪后自动重试；schema 和真实质量失败停止等待检查，不循环消耗推理。当前包装器 PID 为 `2930645`，进程身份及凭据存在性已经核对，等待期间没有子进程、模型缓存结果或虚假完成标记。状态回执见 [supervisor.json](production/runs/dcvlm_canary_v2_20261022/supervisor.json)，更详细的先导状态见 [CANARY_STATUS_20261022.md](production/CANARY_STATUS_20261022.md)。
